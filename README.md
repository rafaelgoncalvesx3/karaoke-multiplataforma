# Karaoke — três versões

- 01_Console_NET: aplicativo de console Windows em C# .NET 8.
- 02_Instalador_Windows: aplicativo Windows com scripts para instalação e geração de instalador.
- 03_Android_TV: projeto Android TV, com workflow do GitHub Actions para compilar o APK.

ATENÇÃO: não estão incluídos EXE ou APK compilados. O workflow Android poderá produzir um APK quando executado em GitHub Actions.

Para publicar no GitHub, crie um repositório vazio e envie as três pastas.
